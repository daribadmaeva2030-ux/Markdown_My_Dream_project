## Project Overview
**EcoTrack** is an app designed to help users track their daily carbon footprint and make small, substainable choices that add up to a big impact,it's built using **HTML**,**CSS**, and **JavaScipt** - but one day, I want to expand it into a full web platform!
_ _ _
## Project Goals
- Build a user-friendly dashboard that tracks:
    - 🌿 *Energy use*
    - 🚗 *Transportation impact*
    - 🍔 *Food consumption*
- Display personalized personalized reports using:
    - `console.log()` to debug progress
